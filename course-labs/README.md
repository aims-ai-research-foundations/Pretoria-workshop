# Course Labs

Notebooks for the end-of-day **Course Lab** sessions (16:30–17:30 SAST on
Days 2–4; Day 1's Course 2 lab runs 15:30–16:30 and Day 5's Course 7 lab
14:00–15:00), organised by day. Click an **Open in Colab** badge to launch a
notebook directly in Google Colab — no local setup required.

Day 1 is here now; the other days land as the week goes on. Days 1–4 run on
CPU with no setup; the Day 5 lab needs a Colab **T4 GPU** and a Hugging Face
token with the Gemma 3 1B and 4B terms accepted — the setup steps arrive with
the notebook in [day5/](day5/).
